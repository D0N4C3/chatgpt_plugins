# D0N4C3 ChatGPT Plugins Marketplace

Personal ChatGPT Desktop & Codex plugin marketplace hosted on GitHub.

## Adding This Marketplace

- **Git URL:** `https://github.com/D0N4C3/chatgpt_plugins.git`
- **Catalog Path:** `.agents/plugins/marketplace.json`
